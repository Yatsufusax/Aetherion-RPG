AETHERION RPG

Un RPG 2D inspirado en los MMORPG clásicos

Versión actual: 0.1 — Planificación
Plataformas: Android y Windows
Motor: HTML5 + JavaScript + Canvas 2D
Modo: Offline / Un jugador

Visión del proyecto

Aetherion RPG es un RPG de fantasía medieval 2D con perspectiva isométrica y estética Pixel Art inspirada en los MMORPG clásicos, especialmente en la experiencia de MU Online de sus primeras temporadas.

El objetivo es crear un universo original que conserve la esencia de los MMORPG clásicos: exploración, combate manual, farmeo, monstruos, equipamiento, joyas, mejoras, jefes y progresión del personaje.

Características principales

- Cámara isométrica fija.
- Pixel Art de fantasía medieval clásica.
- Combate completamente manual.
- Exploración de mapas y mazmorras.
- Sistema de niveles y experiencia.
- Inventario y equipamiento.
- Armas, armaduras y accesorios.
- Drops aleatorios y monedas.
- Joyas y mejoras de equipamiento.
- Monstruos y jefes.
- Guardado local.

Clases iniciales

1. Guerrero.
2. Mago.

4. Caballero Oscuro.
5. Summoner.

Plataformas

- Android: aplicación APK instalable.
